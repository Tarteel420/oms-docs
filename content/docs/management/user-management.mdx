title: User Management
description: Manage the people who log in to OMS and their roles.
---

Select **User Management** under **Management Pages**.

## The user list

Search by username, email or name.

| Column | Shows |
| --- | --- |
| **Username** | Login name (often the email address). |
| **Email** | Email address. |
| **Name** | Full name. |
| **Status** | **Active** or inactive. |
| **Last Login** | Date and time of the last login, or **Never**. |
| **Actions** | **Edit** (pencil), **Manage Roles** (shield), **Delete** (trash). |

## Add a user

1. Select **Add User**. The **Add New User** form opens.
2. Fill in the fields:

| Field | Required |
| --- | --- |
| Username | Yes |
| Email | Yes |
| Password | Yes |
| First Name | No |
| Last Name | No |
| Distributor | No — link the user to a distributor |
| Active | Ticked by default |

3. Select **Add User**.

## Assign a role

1. Select **Manage Roles** (shield icon) on the user's row.
2. In **Manage User Roles**, select **one** role.
3. Select **Save Roles**.

<Screenshot
  file="management/manage-roles.png"
  title="Manage User Roles"
  description="The Manage User Roles dialog with the superadmin, admin, manager and user options."
/>

See [User Roles](/docs/getting-started/user-roles) for what each role is for.

## Edit or delete a user

Use the **Edit** (pencil) or **Delete** (trash) icon on the row.
