title: Distributors
description: Create and manage distributor accounts and their logins.
---

Select **Distributors** under **Management Pages** to open **Distributors Management**.

## The distributor list

Search by name, code, contact or email.

| Column | Shows |
| --- | --- |
| **Name** | Distributor name. The list is sorted by name. |
| **Code** | Distributor code. |
| **Contact** | Contact person. |
| **Email** | Contact email. |
| **Phone** | Contact phone. |
| **Auto-reorder** | **Off**, or **On · selected** / on for all kits. See [Auto-Reorder](/docs/management/auto-reorder). |
| **Status** | **Active** or inactive. |
| **Actions** | **Auto-reorder kits**, **Edit**, **Delete**. |

## Add a distributor

<Steps>
<Step>
### Open the form

Select **Add Distributor**. The **Add New Distributor** form opens.
</Step>
<Step>
### Enter the details

| Field | Required |
| --- | --- |
| Name | Yes |
| Code | No |
| Email | Yes |
| Phone | No |
| Contact Name | No |
| Status | Defaults to **Active** |
| Password | Yes |
| Confirm Password | Yes |
</Step>
<Step>
### Create

Select **Create**.
</Step>
</Steps>

  file="management/add-distributor.png"

/>

<Callout type="info" title="Why a password?">
  The password gives the distributor its own login, so it can manage its own orders directly.
</Callout>

## Edit a distributor

Select **Edit** on the row. The **Edit Distributor** form has the same fields. Leave **Password** and **Confirm Password** blank to keep the current password. Select **Update** to save.

## Delete a distributor

Select **Delete** on the row.
