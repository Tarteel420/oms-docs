---
title: Customers
description: Create and manage end-customer accounts.
---

Select **Customers** under **Management Pages**.

## View customers

1. In **Filter by Distributor**, choose a distributor. The list is empty until you do.
2. Use **Search customers** to narrow the list.
3. The list shows 20 customers per page — use the page buttons at the bottom.

| Column | Shows |
| --- | --- |
| **Name** | Customer name. |
| **Contact** | Contact person. |
| **Location** | City, state and ZIP. |
| **Address** | Street address. |
| **Contact Info** | Phone and email. |
| **Status** | Active or inactive. |
| **Actions** | Row actions. |

## Add a customer

1. Choose the distributor, then select **Add Customer**.
2. Fill in the form:

| Section | Fields |
| --- | --- |
| Basic Information | **Customer Name \***, Contact Name |
| Organization Details (Optional) | Division, Branch, Location |
| Address | **Address Line 1 \***, Address Line 2, Address Line 3, **City \***, **State \***, **ZIP Code \*** |
| Contact Information (Optional) | Phone, Fax, Email |
| Settings | Active, Sort Order |

3. Select **Create Customer**.
