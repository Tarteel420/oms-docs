---
title: Resellers
description: Create and manage resellers under a distributor.
---

Select **Resellers** under **Management Pages**.

## View resellers

1. In **Filter by Distributor**, choose a distributor. The list is empty until you do.
2. Use **Search resellers** to search by name, account ID, contact or phone.

| Column | Shows |
| --- | --- |
| **Name** | Reseller name. |
| **Account Id** | Account ID. |
| **Contact** | Contact person. |
| **Contact Info** | Email and phone. |
| **Status** | Active or inactive. |
| **Actions** | Edit (pencil) and delete (trash). |

## Add a reseller

1. Choose the distributor, then select **Add Reseller**.
2. Fill in the form:

| Section | Fields |
| --- | --- |
| Main | **Reseller Name \***, **Account ID \***, Contact Name |
| Address (Optional) | Address Line 1, Address Line 2, City, State, ZIP Code |
| Contact Information (Optional) | Phone, Email |
| Settings | Active, Sort Order |

3. Select **Create Reseller**.
