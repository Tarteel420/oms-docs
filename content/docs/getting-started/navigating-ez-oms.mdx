## The sidebar

The sidebar on the left groups every page into five sections. Select the arrow at its top edge to collapse it. On small screens, open it with the menu icon at the top left.

| Section | Pages |
| --- | --- |
| **Overview** | [Dashboard](/docs/dashboard), [Orders](/docs/orders), [Invoicing](/docs/reports/invoicing) |
| **Management Pages** | [Products](/docs/products), [User Management](/docs/management/user-management), [Distributors](/docs/management/distributors), [Resellers](/docs/management/resellers), [Customers](/docs/management/customers) |
| **Reports** | [Shipping Analytics](/docs/reports/shipping-analytics), [Safety-Kleen Report](/docs/reports/safety-kleen-report), [Consolidated Invoice](/docs/reports/consolidated-invoice), [Recycling Annual](/docs/reports/recycling-annual-report), [Certificate of Recycling](/docs/reports/certificate-of-recycling) |
| **Return Processing** | [Container Processing](/docs/returns-processing/container-processing), [Product Processing](/docs/returns-processing/product-processing) |
| **Customer Support** | [Complaints](/docs/support) |

## The top bar

| Button | What it does |
| --- | --- |
| **Settings** (gear icon) | Display preferences: **Dark mode**, **Contrast**, **Right to left**, **Compact**, navigation **Layout** and **Color**, color **Presets**, and **Font** family (Public Sans, Inter, DM Sans, Nunito Sans) and size. These change only how the app looks for you. |
| **Account** (your initial) | Shows your username and email, and **Logout**. |

## The floating Scan button

A green **Scan** button stays on the right edge of every page. It opens the **Scan ID** page. See [Scan Kits](/docs/orders/scan-kits).

## Pages outside the sidebar

| Page | How to reach it |
| --- | --- |
| **Order details** | **View Details** on an order. See [Order Details](/docs/orders/order-details). |
| **Scan ID** | Scan Kits buttons or the floating Scan button. |
| **ShipNest Integration** | Administrators only, by its address. See [Integrations](/docs/resources/integrations#shipnest-integration-page). |
| **Public COR lookup** | `/recycle`. See [Customer Certificate Lookup](/docs/returns-processing/customer-cor-lookup). |
