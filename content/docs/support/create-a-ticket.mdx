---
title: Create a Ticket
description: Log a new customer complaint.
---

1. Open **Complaints** and select **New Ticket**. The **Create New Ticket** form opens.

<Screenshot
  file="support/new-ticket.png"
  title="Create New Ticket"
  description="The Create New Ticket form with Order / PO Number, Date, Customer Name, Ticket Type, Priority and Description."
/>

2. Fill in the form:

| Section | Field | Notes |
| --- | --- | --- |
| Ticket Information | **Order / PO Number \*** | The app shows **Order found in system** when the number matches an order. |
| | **Date \*** | Defaults to today. |
| | **Customer Name \*** | |
| Classification | **Ticket Type \*** | General (default), Shipping, Billing, Product, Return, Other. |
| | **Priority \*** | Low, Medium (default), High, Urgent. |
| Details | **Description \*** | What happened and what is needed. |

3. Select **Create Ticket**.
