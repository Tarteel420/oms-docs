---
title: Complaints
description: Manage customer support tickets and complaints.
---

Select **Complaints** under **Customer Support** in the sidebar. Every complaint is a **ticket** linked to an order or PO number.

## The ticket list

| Column | Shows |
| --- | --- |
| **Ticket ID** | For example `#13`. |
| **Order Number** | The related order or PO number. |
| **Customer Name** | Who raised it. |
| **Date** | Ticket date. |
| **Priority** | Low, Medium, High or Urgent. |
| **Status** | Unresolved, Resolved or Completed. |
| **Created By** | The staff member who logged it. |
| **Actions** | **View**, **Edit**, **Mark as Completed**, **Delete**. |

## Filters

| Filter | Options |
| --- | --- |
| **Status** | All Statuses, Unresolved, Resolved, Completed |
| **Priority** | All Priorities, Low, Medium, High, Urgent |
| **Ticket Type** | All Types, General, Shipping, Billing, Product, Return, Other |
| **From Date / To Date** | Ticket date range |
