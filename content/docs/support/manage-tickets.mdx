---
title: Manage Tickets
description: View, edit, complete or delete a complaint ticket.
---

Use the icons in the **Actions** column of the [ticket list](/docs/support).

## View a ticket

Select **View**. **Complaint Details** shows:

- **Ticket information** — order number, customer, date and ticket type.
- **Status & priority**.
- **Description**.
- **Branch remarks** — the branch's response, and who resolved it (for example **Resolved by …**).
- **Record information** — created by, created on and last updated.

## Edit a ticket

Select **Edit**. The **Edit Ticket** form has the same fields as [Create a Ticket](/docs/support/create-a-ticket). Select **Update Ticket** to save.

## Complete a ticket

Select **Mark as Completed**.

## Delete a ticket

Select **Delete**.

## Ticket statuses

| Status | Meaning |
| --- | --- |
| **Unresolved** | Still open. |
| **Resolved** | The branch has resolved it. |
| **Completed** | Closed. |
