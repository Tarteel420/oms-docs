This page explains each part of the [Dashboard](/docs/dashboard).

## Summary cards

The row of cards across the top gives headline figures.

| Card | Meaning |
| --- | --- |
| **Total Orders** | The number of orders in the system. |
| **Total Distributors** | The number of distributor accounts. See [Distributors](/docs/management/distributors). |
| **Total Products** | The number of products in the catalog. See [Products](/docs/products). |
| **Total Revenue** | The total value of orders. |
| **Avg. Order Value** | The average value of an order. |

## Orders Over Time

A chart showing order volume over time. Use it to see whether order volume is steady, rising or falling.

## Orders by Status

A chart showing how many orders are in each status. Use it to see where orders are building up — for example, a large number waiting for labels to be printed.

To understand what each status means, see [Order Statuses](/docs/orders/order-statuses).

## Recent Orders

A table of the latest orders.

| Column | Meaning |
| --- | --- |
| **Order ID** | The order's unique number. |
| **Customer** | Who the order is for. Marketplace orders show the marketplace, such as Amazon. |
| **Date** | When the order was placed. |
| **Total** | The order value. |
| **Status** | The order's current status. |

To work with an order, open it from the [Order List](/docs/orders/order-list).

## Top Products by Price

A table of the highest-priced products, showing **Product Code**, **Description**, **List Price** and **Category**. To manage these products, go to [Products](/docs/products).
