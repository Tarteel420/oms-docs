Select **Certificate of Recycling** under **Reports**. You issue a certificate for a received container: look it up to prefill, then add the processing facility and the weight measured at the dock.

## Issue a certificate

<Steps>
<Step>
### Look up the container

Enter the **unique container ID** or **order number** and select **Prefill**. Renumbered containers are also found by their printed (superseded) number.
</Step>
<Step>
### Check the certificate details

| Field | Notes |
| --- | --- |
| **Unique container ID \*** | Required. |
| Return tracking number | |
| Order number | |
| SKU of recycling kit | Leave it to pull the kit type and details from the catalog. |
| Type of recycling kit | Pulled from the SKU; edit if the paperwork differs. |
| Date shipped | |
| **Date received \*** | Required — this is what the certificate attests to. |
| **Processing facility \*** | Required. Choose a Lighting Resources facility (for example Greenwood, IN; Johnson City, TN; Ontario, CA; Phoenix, AZ). |
| Weight + Unit | **lb** or **kg**. |
</Step>
<Step>
### Check the customer delivery address

**Customer name** is required (the certificate states who the material came from). **City** and **State** are required for the certificate address. Street and ZIP are optional.
</Step>
<Step>
### Add notes (optional)

**Notes** are kept on the register and are not printed.
</Step>
<Step>
### Issue

Select **Issue certificate & download PDF**. Use **Clear form** to start again.
</Step>
</Steps>

## Recently issued

The **Recently issued** table lists certificates (numbered like `COR-000035`) with **Container**, **Order**, **SKU**, **Received**, **Facility**, **Weight**, **Issued by** and **Issued** date.

| Action | What it does |
| --- | --- |
| **Re-print this certificate** | Download the certificate again. |
| **Void** | Cancel the certificate. |

## From an order

In an order's **Return Kits** table, the certificate icon is only available for **delivered** items. See [Bundles and Return Kits](/docs/orders/bundles-and-return-kits).

## Customers can download their own

Customers can download their certificate from the public lookup page. See [Customer Certificate Lookup](/docs/returns-processing/customer-cor-lookup).
