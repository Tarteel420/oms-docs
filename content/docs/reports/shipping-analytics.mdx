---
title: Shipping Analytics
description: Shipping data report by delivery date range.
---

Select **Shipping Analytics** under **Reports**.

## Run the report

1. Under **Date Filters**, choose a **Start Date** and **End Date** (the range is by **delivery date**).
2. Select **Generate Report**.
3. Select **Reset** to clear the dates.

Until a range is chosen, the page shows: *Please select a date range and click "Generate Report" to view shipping data report.*
