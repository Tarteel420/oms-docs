title: Exporting Data
description: Where you can export data from EZ-OMS and in which format.
---

| Where | Export | Format |
| --- | --- | --- |
| [Order list](/docs/orders/order-list) | Selected orders | **Export PDF (n)**, **Export Excel (n)** |
| [Order details](/docs/orders/order-details) | One order | **Export PDF** |
| [Order details](/docs/orders/shipping-labels) | All labels for an order | **Download All Labels** |
| [Safety-Kleen Report](/docs/reports/safety-kleen-report) | Multi-sheet report | Excel |
| [Consolidated Invoice](/docs/reports/consolidated-invoice) | Selected invoice (COVER + SUMMARY sheets) | Excel |
| [Recycling Annual](/docs/reports/recycling-annual-report) | Annual report | Excel |
| [Certificate of Recycling](/docs/reports/certificate-of-recycling) | Certificate | PDF |
| [Container Processing](/docs/returns-processing/container-processing) | Container list | **Export** |
| [Product Processing](/docs/returns-processing/product-processing) | Product list | Excel |
