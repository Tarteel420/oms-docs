---
title: Shipping Labels
description: Download, print and upload labels for an order's bundles and return kits.
---

Labels are handled in the **Bundles & Kits** section of [Order Details](/docs/orders/order-details).

## Download all labels for an order

1. Open the order.
2. In **Bundles & Kits**, select **Download All Labels**.
3. The download contains all **thermal barcode labels (2×3 inch)** and **A4 return kit labels** for the order.

## Print or download one kit's label

In the **Return Kits** table, use the kit's icons:

- **Print Label** — print the label.
- **Download Label PDF** — save the label as a PDF.

## Upload a label PDF for a bundle

Use **Upload PDF Label** on the bundle to attach a label file you already have.

## Change a tracking number

Use **Edit Tracking** or **Delete Tracking** on the return kit.

## Where labels come from

Tracking numbers and labels are produced through ShipNest. See [Integrations](/docs/resources/integrations#shipnest).
