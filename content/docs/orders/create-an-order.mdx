---
title: Create an Order
description: Enter a new order manually with the Create New Order form.
---

Use this for orders that don't arrive automatically from [Amazon, Shopify, email or Safety-Kleen](/docs/orders/order-sources).

## Open the form

1. Select **Orders** in the sidebar.
2. Select **New Order** at the top right. The **Create New Order** form opens.

## Fill in the form

<Steps>
<Step>
### Choose the accounts

- **Distributor \*** — required.
- **Customer** — select an existing customer, or select **Add New** to create one.
- **Reseller (Optional)** — select a reseller, or select **Add New** to create one.
</Step>
<Step>
### Enter the ship-to details

| Field | Required |
| --- | --- |
| Customer Name | Yes |
| Customer Contact Name | No |
| Phone | No |
| Email | No |
| City | Yes |
| State | Yes |
| Zip Code | Yes |
| Address Line 1 (street address, P.O. box, company name) | Yes |
| Address Line 2 (apartment, suite, unit, building, floor) | No |
</Step>
<Step>
### Enter the order details

**Order PO Number**, **Order Date** (defaults to today), **Need Date**, **Notes** and **Comments**. All are optional.
</Step>
<Step>
### Add products

Under **Add Products**, choose a product in **Select Product**, enter the **Quantity** and select **Add**. Repeat for each product.
</Step>
<Step>
### Create the order

Select **Create Order**. Select **Cancel** to close the form without saving.
</Step>
</Steps>

## What happens next

The new order appears in the [order list](/docs/orders/order-list). Open it to check its [items](/docs/orders/order-items) and [bundles and kits](/docs/orders/bundles-and-return-kits).

<Callout type="warn" title="Check before saving">
  An order can only be edited later while its status is **Not Specified** or **Aggregated**. Check the address and products before selecting **Create Order**.
</Callout>
