---
title: Order Documents
description: Upload, print and export PDFs for an order.
---

The buttons at the top of [Order Details](/docs/orders/order-details) handle order-level PDFs.

## Upload a PDF

1. Select **Upload**. The **Upload PDF for Order #…** dialog opens.
2. Drag and drop a PDF, or click to select a file.
3. Only **PDF** files up to **10 MB** are accepted.

## Print the uploaded PDF

Select **Print** to print the PDF uploaded for the order.

## Export the order as a PDF

Select **Export PDF**.

To export several orders at once, select them in the [order list](/docs/orders/order-list) and use **Export PDF (n)** or **Export Excel (n)**.
