---
title: Order Sources
description: The different ways orders reach EZ-OMS.
---

| Source | How it arrives |
| --- | --- |
| **Amazon** | Pulled in automatically through the Amazon integration. Shown with an orange **Amazon** badge in the order list. |
| **Shopify** | Pulled in automatically through the Shopify integration. |
| **Email** | Brought in automatically through a Microsoft Graph mailbox connection. |
| **Safety-Kleen mail-back** | Brought in through the same Microsoft Graph connection. |
| **Manual entry** | Created by staff with **New Order**. See [Create an Order](/docs/orders/create-an-order). |
| **Customer self-service** | Placed by customers with their own access (in pilot). See [Customer Ordering](/docs/orders/customer-ordering). |

## How marketplace orders look

Amazon orders appear with the customer **\*Amazon Orders**, the Amazon order number in the **PO Number** column (for example `AMAZON 112-…`) and the distributor **EZ ON THE EARTH - HOUSE**.

<Callout type="info" title="Amazon and Shopify billing">
  Amazon and Shopify orders are billed on those platforms, so they are excluded from [Invoicing](/docs/reports/invoicing).
</Callout>
