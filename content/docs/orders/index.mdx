## Typical workflow

1. The order arrives automatically or is [created manually](/docs/orders/create-an-order).
2. Bundles and return kits are created with their tracking numbers — see [Bundles and Return Kits](/docs/orders/bundles-and-return-kits).
3. Labels are [downloaded and printed](/docs/orders/shipping-labels).
4. Kits are assembled and [scanned](/docs/orders/scan-kits).
5. The order ships and is [tracked](/docs/orders/shipment-tracking).
6. The order is [invoiced](/docs/reports/invoicing), and returned kits receive a [certificate of recycling](/docs/reports/certificate-of-recycling).
