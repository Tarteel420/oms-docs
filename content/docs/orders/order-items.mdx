The **Order Items** section of [Order Details](/docs/orders/order-details) lists every product on the order.

| Column | Shows |
| --- | --- |
| **SKU** | The product code, for example `35BT`. |
| **Description** | The product name. |
| **Quantity** | How many were ordered. |
| **Unit Price** | Price per unit. |
| **Total** | Quantity × unit price. |
| **Actions** | Edit and delete icons. |

The **Order Total** is shown below the table.

## Add an item

1. Select **Add Item**. The **Add New Order Item** dialog opens.
2. Choose the product in **Select Product \***.
3. Select **Add Item**.

## Edit or remove an item

- Select the **pencil** icon to edit an item.
- Select the **trash** icon to delete it.

<Callout type="info">
  An order must keep at least one item — the delete icon is disabled on the last item (**Cannot delete last item**). On some orders, such as shipped Amazon orders, **Add Item** is disabled.
</Callout>
