---
title: Update or Cancel an Order
description: When an order can be edited, and how to cancel one.
---

## Edit an order

Select **Edit Order** at the top of [Order Details](/docs/orders/order-details).

<Callout type="warn" title="When editing is allowed">
  An order can only be edited when its status is **Not Specified** or **Aggregated**. For any other status the **Edit Order** button is disabled.
</Callout>

Even when the order itself can't be edited, you may still be able to change its [items](/docs/orders/order-items), [bundles and kits](/docs/orders/bundles-and-return-kits) and [notes](/docs/orders/order-notes).

## Cancel an order

1. Open the order.
2. In the **Order Information** card, under **Need to cancel this order?**, select **Cancel order**.
3. The order moves to **Cancelled**.

You can also set the status to **Cancelled** with the status dropdown. See [Change Order Status](/docs/orders/change-order-status).
