---
title: Order Notes
description: Add and edit notes on an order.
---

Notes keep internal information with the order.

## From the order list

1. In the **Notes** column, select **Add Notes** (or **View/Edit** if the order already has notes).
2. The **Order #… Notes** dialog opens.
3. Type in **Notes** and select **Save**.

## From the order page

1. Open [Order Details](/docs/orders/order-details).
2. Type in the **Notes** card ("Add notes about this order…").
3. Select **Save Notes**.

<Callout type="info">
  The **Create New Order** form also has **Notes** and **Comments** fields. See [Create an Order](/docs/orders/create-an-order).
</Callout>
