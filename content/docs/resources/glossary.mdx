---
title: Glossary
description: Definitions of the terms used across OMS.
---

| Term | Definition |
| --- | --- |
| **admin / superadmin / manager / user** | The user roles. See [User Roles](/docs/getting-started/user-roles). |
| **Aggregated** | An order status in which the order can still be edited. |
| **Auto-reorder** | A distributor setting that creates a new order when a return kit is delivered. See [Auto-Reorder](/docs/management/auto-reorder). |
| **Bundle** | The packaging shipped to the customer, containing one or more return kits. See [Bundles and Return Kits](/docs/orders/bundles-and-return-kits). |
| **Bundle size** | The default number of kits per bundle, set on the kit type. |
| **Certificate of recycling** | A certificate issued for an order that has been received and processed. See [Certificate of Recycling](/docs/reports/certificate-of-recycling). |
| **Container ID** | The RMA number that uniquely identifies a return kit's container. |
| **Container number** | The unique ID of a return kit's container, printed on its label. Customers use it to find their certificate. |
| **COR** | Certificate of Recycling. |
| **Customer** | The end user who receives kits, fills them and ships them back. See [Customers](/docs/management/customers). |
| **Distributor** | A company that provides recycling kits to resellers and customers. See [Distributors](/docs/management/distributors). |
| **Distributor price** | A distributor-specific price for a kit type. |
| **Easy on the Earth** | The customer-facing brand for Lighting Resources' recycling program. |
| **GreenLoop** | The system the warehouse uses to record received products. |
| **Inbound label** | The return label on each kit, addressed to the warehouse. |
| **Kit category** | A grouping of kit types, for example by size or material. |
| **Kit type** | A kind of recycling kit, set up as a product in the catalog. See [Add a Product](/docs/products/add-a-product). |
| **List price** | The global price of a kit type. |
| **LRI** | Lighting Resources, one of the main users of OMS. |
| **Needs Review** | A flag on orders that need a check. |
| **Negotiated Price** | A distributor's agreed price for a product. |
| **Order number** | The unique number generated for each order. |
| **Outbound label** | The label used to ship a bundle to the customer. |
| **Ready to Invoice** | A flag on orders that can be invoiced. |
| **Reseller** | An intermediary under a distributor that sells kits to its own customers. See [Resellers](/docs/management/resellers). |
| **Return kit** | An individual container the customer fills and sends back, with its own tracking number. |
| **RMA number** | See Container ID. |
| **Safety-Kleen** | A source of orders, received through its mail-back system, with its own invoice report. |
| **Scan ID** | The page where kit Unique IDs are scanned to mark kits assembled. See [Scan Kits](/docs/orders/scan-kits). |
| **ShipNest** | The shipping platform used for labels and tracking. See [Integrations](/docs/resources/integrations#shipnest). |
| **SKU / Kit code** | The unique identifier of a kit type. |
| **Ticket** | A customer complaint in [Complaints](/docs/support). |
| **Tracking number** | The unique number used to track a bundle or return kit shipment. |
