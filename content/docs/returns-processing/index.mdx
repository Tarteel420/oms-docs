---
title: Returns Overview
description: What happens when filled kits come back, and the Return Processing tools.
---

After a customer fills a kit, they ship it back using the return label. From there:

```
Return kit shipped back → Delivery date recorded → Certificate of recycling issued
                                 └→ Auto-reorder creates a new order (if enabled)
```
