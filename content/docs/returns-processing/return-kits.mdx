---
title: Return Kits
description: Follow returned kits and what happens when one is delivered.
---

Each order's return kits are listed in the **Return Kits** table inside **Bundles & Kits** on [Order Details](/docs/orders/order-details).

## What to check

| Column | Meaning |
| --- | --- |
| **Container Number** | The kit's unique container ID. |
| **Tracking** | The return tracking number. |
| **Delivery Date** | Filled in once the returned kit has been delivered. |
| **Cert. of Recycling** | The certificate for the kit. |

## When a kit is delivered

- The **Delivery Date** is recorded.
- The **certificate of recycling** can now be generated — the certificate icon is only available for delivered items. See [Certificate of Recycling](/docs/reports/certificate-of-recycling).
- If the distributor has [auto-reorder](/docs/management/auto-reorder) on, a new order tagged **PENDING - AUTOREORDER** is created automatically.

## Partial returns

The status list includes **Partial Return**, used for orders where only some kits have come back. See [Order Statuses](/docs/orders/order-statuses).

## Find a returned kit

- Search the [order list](/docs/orders/order-list) with the **Tracking Number** filter.
- Look up the container on [Certificate of Recycling](/docs/reports/certificate-of-recycling).
