Select **Container Processing** under **Return Processing**.

<Callout type="info">
  Container and Product Processing come from the legacy Safety-Kleen processing system and are used by specific Lighting Resources branches.
</Callout>

## Find containers

- **Search** by customer, order number or tracking number.
- **Sort By**: **ID**, **Return Date** or **Created Date**.
- Rows per page: 25 by default.

| Column | Shows |
| --- | --- |
| **Order #** | The order. |
| **Customer** | Customer name. |
| **City/State** | Location. |
| **Product #** | Product number. |
| **Lithium** | Lithium flag. |
| **Fee** | Processing fee. |
| **Certificate #** | Certificate number. |
| **Tracking #** | Tracking number. |
| **Weight** | Weight. |
| **Return Date** | Return date. |
| **Actions** | Row actions. |

## Add a container

1. Select **New Container**.
2. Fill in the form:

| Field | Required |
| --- | --- |
| Order ID | Yes |
| Customer Name | Yes |
| Street, City, State, Zip | No |
| Product Number | Yes |
| Product Description | No |
| Lithium Flag | Defaults to **No** |
| Processing Fee | Defaults to 0 |
| Certificate Number | No |
| Tracking Number | No |
| Weight (lbs) | No |
| Return Date | No |

3. Select **Create**.
