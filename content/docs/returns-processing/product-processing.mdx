## Find products

- **Search** by SKU or description.
- **Created date range** filter; **Clear** resets filters.

| Column | Shows |
| --- | --- |
| **SKU** | Product code. |
| **Description** | Product description. |
| **Capacity** | Container capacity. |
| **Processing Fee** | Fee to process. |
| **Lithium Fee** | Lithium battery surcharge. |
| **Weight (lbs)** | Weight. |
| **Created By** | Who added it. |
| **Actions** | Row actions. |

## Add a product

1. Select **New Product**.
2. Enter **SKU \*** and, optionally, **Description**, **Capacity**, **Processing Fee**, **Lithium Battery Surcharge** and **Weight (lbs)**.
3. Select **Create**.

## Export

Select **Export to Excel**.

<Callout type="info">
  These processing products are separate from the recycling kit catalog in [Products](/docs/products).
</Callout>
