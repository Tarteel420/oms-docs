---
title: Product Management
description: The catalog of recycling kits, with each distributor's prices.
---

Select **Products** under **Management Pages** to open **Product Management**. Each product is a recycling kit — for example `35BT – Dry Cell Battery (3.5 Gallon) Recycle Kit` or `40JM – Straight Lamp (4 Foot Jumbo) Recycle Kit`.

## Find products

| Control | Use it to |
| --- | --- |
| **Distributor** | Show one distributor's products, or **All Distributors**. Use the **×** to clear it. |
| **Search** | Search by name, code, category or distributor. |

## Columns

| Column | Shows |
| --- | --- |
| **Image** | The product picture. |
| **Product Code** | The SKU. The list is sorted by this column. |
| **Name** | The product description. |
| **Category** | See [Product Categories](/docs/products/product-categories). |
| **Distributor** | The distributor this product record belongs to. |
| **List Price** | Standard price. |
| **Negotiated Price** | The distributor's agreed price. |
| **Actions** | Row actions for the product. |

## How pricing works

Products are stored **per distributor**. The same kit can exist for several distributors, each with its own **List Price** and **Negotiated Price**.

## Where products come from

- Created here with **Add Product**. See [Add a Product](/docs/products/add-a-product).
- Products sold on Amazon or Shopify are also created on those sites.

<Callout type="warn" title="Empty list">
  During the walkthrough for this guide, the product list showed **No products found** even with **All Distributors** selected, although the Dashboard counts more than 5,000 products. If you see the same, report it to the development team.
</Callout>
