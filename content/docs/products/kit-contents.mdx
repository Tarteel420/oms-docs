A kit that ships to a customer usually includes more than the container itself.

## What's in a kit

Taking a battery kit as an example, the shipment includes:

| Item | Notes |
| --- | --- |
| **The container** (for example, a bucket) | The product itself — this is what is set up in the [catalog](/docs/products). |
| **Instructions** | Printed item. |
| **Order summary** | For the customer. |
| **Warnings** | Printed item. |
| **Standards and compliance information** | Printed item. |
| **Return label** | For shipping the filled kit back. See [Shipping Labels](/docs/orders/shipping-labels). |

Only the container is a product. The other printed items are complementary items that go with it.

## Who manages kit contents

The complementary items are **predefined and managed by the warehouse**. OMS does not currently link these items to the product.

<Callout type="info" title="Planned improvement">
  A kit breakdown system is being developed with StockWise and the BTO kit system to split each order into its separate items (container, pages, labels and so on). This is not yet available in OMS.
</Callout>
