---
title: Product Categories
description: The categories products can be grouped into.
---

When adding a product, **Category (Optional)** offers:

| Category |
| --- |
| No Category |
| None Specified |
| Lamps |
| Mercury Service |
| Batteries |
| Ballast & eScrap |
| Exit Signs |
| Smoke Detectors |

Use the category to group similar kits. The product list can be searched by category name.
